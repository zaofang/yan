# A home for Yan

Yan now has a website. It holds four things:

- the [tour](../tour/), seven short chapters, each program runnable;
- the [playground](../play/), which checks and runs a module in your browser and shows it in every
  surface at once;
- the [status page](../status/), generated from the repository on every deploy;
- this blog.

Everything is static. The playground is the compiler built to WebAssembly: your code never leaves the
page. The Share button puts the program in the link itself, so a shared program needs no server either.
