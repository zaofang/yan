# Yan themes

Generated by `uv run python -m tools.themes` from `site/brand/tokens.json`; CI fails if they are out of date.
Change the tokens, not these files.

- `yan-dark.color-theme.json`, `yan-light.color-theme.json`: VS Code colour themes, including the terminal palette.
- `yan-dark.ghostty`, `yan-light.ghostty`: Ghostty palettes (`config-file = path/to/yan-dark.ghostty`).

Every text role meets 4.5:1 on its ground in both themes (`tools/selftest/test_themes.py`).
