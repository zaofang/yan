# Ben

Ben is a programming language with one core and two surfaces.

- **Fan**: a typed, Python-shaped syntax optimized for LLM authors, measured in total tokens per solved task.
- **Wen**: the human syntax.

Both compile to the same Ben core, which is fast, concurrent, deterministic and capability-safe.
The implementation starts as a Python reference and is ported to Rust.

The developer owns the spec, tests and gates; agents write the code and never edit tests.
Authoritative documents: Spec v0.2 and the 1.0 Development Roadmap.
