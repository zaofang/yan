## Where pass@1 is lost

Yan Agent fails pass@1 on 27 (Sonnet) and 46 (Haiku) normal tasks. Of those, 18 and 23 had checker
diagnostics on the first body reply; 9 and 23 had none (hidden-case failures with the model's tests
green, `STOP:` replies, shared MBPP ambiguity). Codes on the first body reply of failing tasks:

| Code | Sonnet | Haiku | Typical message |
|---|---|---|---|
| E201 type mismatch | 17 | 13 | `expected str, found char`; cannot compare `char` with `str`; `iter` indexed |
| E200 no such function or method | 1 | 4 | no function takes a `str` first |
| W806 | 0 | 3 | special-cased branch |
| E017, E413, E315, E545, E221 | 0 | 8 | one to two tasks each |

E201 from `char` against one-character `str` (accepted lowering candidate 1) and from indexing a
single-pass `iter` remains the dominant cause for both models. E241 is no longer a top cause. Haiku's
remaining losses are spread over single-task diagnostics plus 23 failures with no diagnostic.
