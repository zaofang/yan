arm also fails are not a Yan Agent gap.

## New spec-phase cost: E241 on `[]` in `ex` lines

E241 (empty `[]` needs a type annotation, R808) was the top checker code before repair: 9 spec-phase
round-0 rejections for Sonnet, 14 for Haiku (12 round 0, one each in rounds 1 and 2). It appears when
the model writes an empty list inside an `ex` line, for example `ex find_last_occurrence([], 3) == -1`.
Nearly all are repaired in one round, so they cost a repair round and tokens, not pass@1. This is the
largest single removable item in Haiku's 21 repair rounds. Candidate fix: take the type of an empty
literal in an `ex` argument from the parameter type of the call. That is a lowering/inference proposal
for the lead, not done here.

Other pre-repair codes (all rounds): Sonnet P003 7, W806 5, E201, E210, E017, E301 1 each; Haiku P003 16,
E201 5, E200 5, E100 4, E203 3, W806 3, E221 2, E619 2, E210 2.
