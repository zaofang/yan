# Guides

Read in this order.

1. [Getting started](getting-started.md): install, then six programs from `examples/real/`.
2. [Contributor guide](contributing.md): workflow, differential runs, fuzzing, conformance cases, spec rows, `--ub`.
3. [Known gaps](known-gaps.md): what does not work yet, with repros and issues.

Reference guides: [syntax highlighting](syntax-highlighting.md), [TypeScript](typescript.md), [versioning](versioning.md).

Code blocks in these pages are checked: `uv run python docs/guides/check.py` (see the fence options in its docstring).
The spec in [`spec/`](../../spec/README.md) is the authority; guides link it and never copy it.
